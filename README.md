# NoReelsGram
WebView wrapper for instagram.com that blocks Reels.

## Build (pick one)
1. Android Studio: File > Open this folder, let Gradle sync, then Build > Build APK(s).
   Output: app/build/outputs/apk/debug/app-debug.apk
2. GitHub: push this folder to a repo; Actions > "Build APK" > download the artifact.

Install the APK on your phone (allow "install unknown apps"), then log in as usual.
